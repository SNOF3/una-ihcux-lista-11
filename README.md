Proposta de Valor

O principal benefício do ReCiclo é facilitar a conexão entre pessoas que querem fazer e quem precisa, promovendo a sustentabilidade e o reaproveitamento de recursos. O app reduz desperdícios, ajuda as comunidades e ainda gera senso de recompensa por meio da gamificação (Selos Eco), incentivando boas práticas ambientais.

Descrição das Telas

Tela Feed / Home É a tela inicial do aplicativo. Exibe uma lista de itens disponíveis ao usuário, com imagem, título, estado de conservação e distância. Permite rolagem, acesso rápido aos detalhes de cada item e a opção de cadastrar um item para doação.

Tela de Filtros de Busca Permite ao usuário refinar a busca de itens. Inclui opções como:

Categoria (móveis, roupas, jardins, etc.)

Distância (ex: até 5 km, 10 km)

Estado de conservação.

Após aplicar os filtros, o feed é atualizado.

Tela de Detalhes do Item Mostra informações completas do item selecionado:

Fotos
Descrição
Categoria e estado
Localização:
Perfil do doador
Possui botão para entrar em contato (chat) e manifestar interesse no item.
Tela de Cadastro de Novo Item Voltada para doadores cadastrarem um item. Inclui:

Carregar foto
Título e descrição
Categoria
Estado de conservação
Localização
Forma de retirada
Ao finalizar, o item é publicado no feed.

Tela de Chat / Mensagens Permite a comunicação entre doadores e interessados. Os usuários combinaram detalhes como local e horário de retirada. Interface simples, semelhante a aplicativos de mensagem.

Tela de Perfil do Usuário Apresenta:

Dados do usuário
Histórico de doações/interesses
Selos Eco conquistados (gamificação)
Incentivo ao engajamento contínuo.
Jornada Principal do Usuário O usuário abre o aplicativo e acessa a Tela Home (Feed). Navegue pelos itens disponíveis ou utilize a Tela de Filtros para refinar a busca. Selecione um item e acesse a Tela de Detalhes. Demonstre interesse clicando em “Quero este item”. Para tirar dúvidas e combinar a retirada do item, clique em "Enviar mensagem". É direcionado para a Tela de Chat, onde conversa com o doador. Ambos combinam a retirada do item. Após a conclusão da doação, o sistema registra a ação. O usuário recebe um Selo Eco visível na Tela de Perfil, incentivando novas interações.
